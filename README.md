# 扣抵值選股自動監測系統

依「扣抵值選股策略」自動盯盤：收盤篩股、盤中警示、每週復盤，通知發到專屬 Telegram，並提供一頁儀表板。

- **儀表板**：https://lun-ku.github.io/koudi-monitor/dashboard.html （手機免登入、每 180 秒自動刷新）
- **策略依據**：`../000_Agent/knowledge/扣抵值選股策略.md`

---

## 一、系統在做什麼（五大功能）

| 功能 | 說明 |
|---|---|
| 持續掃描 | 盤中每 30 分、收盤各自動抓資料判斷一次 |
| 觸發警示 | 符合進出場條件就發 Telegram 通知 |
| 狀態監控 | 追蹤持倉的止損、賣訊、移動出場 |
| 主動復盤 | 每週統計警示準不準 |
| 觀察清單 | 貼報告書 → 解析候選 → 增刪追蹤名單 |

全部跑在雲端（GitHub Actions），電腦不用開。

## 二、策略規則（扣抵值）

**進場條件**（觀察清單）：站上「扣抵值」且突破「昨日高點」才算觸發，進場即設停損（通常昨日低點，風險約 1.5–3%）。

**出場條件**（持倉）：
- 止損：跌破停損價就出
- 第一賣訊：跌破扣抵值
- 移動出場：守住扣抵值續抱；扣抵值變高＋長上引線／大黑K／跌破 → 獲利了結

**停損時間規則**（防盤中下影線洗出場，`strategy.stop_gate`）：
- 13:15 前小幅跌破 → 先按住不發
- 任何時間急殺跌破停損價逾 7% → 立即通知
- 13:15 仍沒站回停損價 → 發確認出場通知

## 三、自動排程（台灣時間）

| 時間 | 動作 |
|---|---|
| 09:08–12:38 每 30 分、13:08 | 盤中掃描（發訊號＋更新儀表板）|
| 13:22 | 停損確認掃描 |
| 14:38 | 收盤掃描（重抓日K、篩股評分、更新儀表板）|
| 週六 10:08 | 每週復盤 |

盤中掃描只在台灣 09:00–13:35 動作，遲到的排程自動略過。

## 四、儀表板怎麼看

- **持倉區**：止損、賣訊(扣抵值)、移動出場、距離，最該注意的排最前面
- **觀察清單區**：進場觸發、距觸發、停損、風險、濾網狀態
- 台股習慣：紅＝漲、綠＝跌
- 關鍵價位（止損／扣抵值／觸發）為當日固定值、由前一日收盤算出，與盤中提醒一致；盤中套即時價、收盤套收盤價

## 五、日常怎麼用

| 你想做 | 做法 |
|---|---|
| 換觀察名單 | 貼報告書，請 AI 解析後更新 `watchlist.json` |
| 加減持倉 | 更新 `positions.json`（見下方指令）|
| 補成本（才有損益、停利目標）| 持倉加 `成本=` 欄位 |
| 看最新狀態 | 直接開儀表板網址（自動更新）|

## 六、已知限制

- **盤中通知不保證準時**：GitHub 免費排程忙碌時會延遲甚至漏跑。有跳就是有效訊號、時間戳記會顯示；收盤報告與週報不受影響。
- **盤中是簡化版訊號**：只比現價與關鍵價位，不做五分K量能突破確認，進場前請自行看盤確認。
- **資料新鮮度保護**：某檔最新 K 線離今天超過 6 天（殘缺/漏抓）時，盤中自動跳過該檔。
- **儀表板網址公開**：內容只有股票清單與技術價位，無帳號金額。
- 本系統為技術面判斷輔助，非投資建議，也不會自動下單。

## 技術參考

### 第一次設定
1. Telegram：找 `@BotFather` → `/newbot` → 取金鑰 → 打開機器人按 START → `python3 tg_setup.py <金鑰>`（寫入 `.env`）
2. 雲端：repo 已公開並啟用 GitHub Pages；金鑰放 GitHub Secrets 的 `TG_BOT_TOKEN`、`TG_CHAT_ID`

### 常用指令
```bash
python3 fetch_k.py            # 抓日 K（上月用快取、當月重抓）
python3 close_scan.py         # 收盤掃描（含重建儀表板）
python3 intraday_scan.py      # 盤中掃描（含即時儀表板）；加 --dry 只印不發
python3 weekly_review.py      # 每週復盤
python3 build_dashboard.py    # 產儀表板；加 --realtime 用即時價
open dashboard.html           # 本機開啟儀表板
```

### 觀察清單／持倉管理
```bash
python3 update_watchlist.py --add 2330=台積電 --remove 1301 --list --prune-kills
python3 manage_positions.py  --add 2330 成本=2380 股數=1000 停損=2370 目標=3000
python3 manage_positions.py  --remove 2330 --list
```
抓資料與掃描範圍＝觀察清單 ∪ 持倉。

### 檔案
| 檔案 | 用途 |
|---|---|
| `watchlist.json` | 觀察清單（代號:名稱）|
| `positions.json` | 持倉（成本／股數／停損／目標，皆選填）|
| `kdata.json` | 日 K 快取 |
| `alert_log.json` | 警示紀錄，供復盤統計 |
| `strategy.py` | 策略大腦：濾網、評分、進出場訊號、盤中關鍵價位、停損閘控 |
| `quote.py` | TWSE 即時報價（免登入，tse/otc 自動 fallback）|
| `build_dashboard.py` | 產儀表板 HTML |
| `notify.py` / `tg_setup.py` | Telegram 發送與設定 |
| `.github/workflows/monitor.yml` | 雲端排程 |
| `.env` | 機密（已 gitignore，不進版控）|

### 排程與部署
- cron 在 `monitor.yml`（UTC，台灣 +8；分鐘刻意避開整點降低誤點）
- 每次執行後把 `kdata.json`／`alert_log.json`／`dashboard.html` commit 回 repo；push 後 GitHub Pages 自動刷新儀表板
